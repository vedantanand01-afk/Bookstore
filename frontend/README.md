# BookNest Frontend

A polished React + Vite bookstore dashboard built for resume presentation.

## Features

- Responsive book inventory dashboard with card and table views
- Search, genre filtering, and sorting controls
- CRUD forms for create/edit/delete workflows
- Detailed preview popup and full detail page
- Modern UI with Tailwind-style utility classes
- Integration with backend API endpoints for data persistence

## Run locally

```bash
cd frontend
npm install
npm run dev
```

## Build

```bash
npm run build
```
